# Sample docs folder

Drop your exported internal docs here (markdown, .txt, .docx, or .pdf) and
`build_index.py` will pick them up automatically -- this is what config.py's
`local_docs` source points at by default.

This file itself is just a placeholder so the folder exists and there's
something to index on your first test run.

## Example: how this team deploys

This is a made-up example doc so you can see the onboarding agent cite a
"doc" source distinct from a code file. In a real setup, this folder would
hold things like runbooks, architecture decision records, or onboarding
guides exported from Confluence/Notion/ADO wiki.
